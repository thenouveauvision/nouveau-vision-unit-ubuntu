# NVUN 1.0.0 Binary Payload

The qualified NVUN 1.0.0 runtime binaries are intentionally not stored
in ordinary Git history in this repository.

Qualified binaries:

- `bin/nvund`
- `bin/nvu-cli`

Their expected SHA-256 hashes are recorded in `SHA256SUMS`.

The graduated runtime binaries are distributed through the signed
Nouveau-Vision Unit Debian package from:

https://apt.nvu.us/

The public Ubuntu distribution package is:

`nvu 1.0.0-2 amd64`

The existing NVUN project repository remains the source/build home for
NVUN pending a deliberate future repository consolidation decision.
